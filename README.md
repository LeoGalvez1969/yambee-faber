# Yambee Faber · Landing Page

Landing page del **Centro Yambee Faber** — Centro de bienestar holístico-energético con tecnologías óptico-acústicas y PEMF en Cuernavaca, Morelos.

## Estructura

- `index.html` — landing page completa (HTML + CSS + JS inline)
- `img/` — fotos del consultorio e ilustraciones

## Deploy

Desplegado en Vercel como sitio estático. No requiere build.

## Stack

- HTML5 + CSS3 puro
- Tipografías: Cormorant Garamond + Inter Tight (Google Fonts)
- Sin frameworks ni dependencias externas
